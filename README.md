# Sales data — Excel

**Author:** Salimeda Deekshith  

Excel analysis (cleaning, calculated fields, pivot tables) for the same sales dataset used in the Python repo.

**Dataset:** [Kaggle — sales-dataset](https://www.kaggle.com/datasets/vinothkannaece/sales-dataset)  
**Python part (tasks 5–12):** [python-sales-analysis](https://github.com/Deekshith254/python-sales-analysis)

## How to run

1. Open **`Sales_Data_Analysis.xlsx`**
2. Follow **`docs/EXCEL_STEPS.md`** to complete tasks 1–4.

## Outputs

| Output | How it is produced |
|--------|---------------------|
| Cleaned data, formulas, pivots | Saved inside **`Sales_Data_Analysis.xlsx`** as you work |
| Cleaning notes | Short log sheet in the same workbook (task 1) |

Use the same Kaggle **`sales_data.csv`** as in the Python repo (`data/`).

## Files

| File | Description |
|------|-------------|
| `Sales_Data_Analysis.xlsx` | Workbook — Part A (tasks 1–4) |
| `docs/EXCEL_STEPS.md` | Step-by-step instructions |
| `data/sales_data.csv` | Reference copy of the dataset |
